# 🎲 Lottery Game

A simple and interactive Lottery Game built with **React**. Generate random lottery tickets and check whether you've won based on the winning condition.

## 🚀 Features

- Generate random lottery tickets
- Instant win/loss result
- Clean and responsive UI
- Built using React components and hooks
- Demonstrates props, state, events, and conditional rendering

## 🛠️ Technologies Used

- React
- JavaScript (ES6+)
- CSS
- Vite

## 📂 Project Structure

```text
src/
├── App.jsx
├── LotteryPage.jsx
├── Ticket.jsx

├── Button.jsx
├── helper.js
└── CSS Files
```

## 🎮 How to Play

1. Open the application.
2. Click the **Buy Ticket** button.
3. A random ticket is generated.
4. If the ticket satisfies the winning condition, you win!
5. Otherwise, try again by buying another ticket.

## 📦 Installation

```bash
git clone <your-repository-url>
cd Lottery-Page
npm install
npm run dev
```
